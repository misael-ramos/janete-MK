# Fotos das clientes (depoimentos)

Opcional: fotos das clientes que deram depoimento.

- Formato: .jpg ou .webp, quadradas (mínimo 200x200px)
- Se não usar fotos, o site já mostra as iniciais em um círculo dourado

Para usar foto, substitua no index.html:
<span class="depoimento__avatar">JU</span>
por:
<img class="depoimento__avatar" src="assets/img/depoimentos/juliana.jpg" alt="Juliana M.">
